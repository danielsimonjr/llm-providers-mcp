# gemini skill

Load id: `llm-gemini:gemini`. Slash trigger: `/gemini`.

Routes questions to Google Gemini via the `llm-gemini` MCP server: `gemini_quick_query` (gemini-2.5-flash) for everyday questions, `gemini_reasoning_query` (gemini-2.5-pro) for multi-step reasoning and complex analysis, and `gemini_multimodal_query` for image/multimodal input.

See `SKILL.md` for the full playbook — tool selection, answer format, and the multimodal gotcha.
